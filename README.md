# 🥑 Мой Баланс (Дневник Питания)

**Мой Баланс** — это легковесное, быстрое и полностью конфиденциальное мобильное приложение на Flutter для отслеживания ежедневного рациона и контроля КБЖУ (Калории, Белки, Жиры, Углеводы). Приложение создано для тех, кто хочет держать форму, находиться в дефиците или профиците калорий без перегруженных и навязчивых интерфейсов.

## ✨ Основные возможности

* **Гибкий дневник питания:** Возможность группировать продукты по блюдам/приемам пищи (например, «Яичница», «Суп» и т.д.).
* **Редактирование дневника:** Откройте детали блюда и нажмите карандаш рядом с продуктом, чтобы изменить название блюда, ингредиент, КБЖУ и вес уже сохранённой записи.
* **Динамический коэффициент порции:** Уникальная фича прямого редактирования коэффициента блюда (например, введя `0.5` или `1.2`), которая мгновенно пересчитывает КБЖУ всех ингредиентов без необходимости переписывать каждый продукт отдельно.
* **База продуктов:** Ищите продукты во встроенном офлайн-каталоге и добавляйте их в личную базу. Свои продукты можно вручную добавлять, редактировать и удалять; каталог работает без регистрации и интернета.
* **Умный расчет целей:** Интегрированный профиль пользователя, рассчитывающий норму поддержания веса и целевой дефицит калорий.
* **Профиль:** Сохраняйте ФИО, возраст, рост, вес, цель и уровень активности для расчёта персональной нормы КБЖУ.
* **Отчёт по питанию:** Нажмите значок отправки в профиле, выберите диапазон дат и поделитесь отчётом через мессенджер. Отчёт содержит параметры человека, потреблённые и целевые калории, белки, жиры и углеводы.
* **Распознавание блюда по фото:** На вкладке «ИИ фото» сфотографируйте блюдо или выберите изображение. Gemini приблизительно определит блюдо, ингредиенты и КБЖУ на 100 г; результат и оценка веса порции откроются в форме добавления и попадут в дневник только после подтверждения. Фото предварительно уменьшается, а при временной перегрузке API запрос повторяется до трёх раз с короткой задержкой.
* **Календарная история:** Просматривайте и редактируйте логи питания за любой прошедший или будущий день.
* **Локальное хранение:** Профиль, дневник и личная база хранятся на устройстве в `Hive`; поиск по каталогу выполняется полностью офлайн.
* **Оформление:** Светлая природная палитра и полупрозрачные стеклянные панели объединяют дневник, распознавание блюд и профиль.

Для распознавания откройте профиль, нажмите значок ключа/Gemini рядом с кнопкой «Поделиться» и вставьте свой API key. Ключ хранится в локальном хранилище приложения на устройстве; передавать его через параметры сборки не требуется. APK можно собирать обычной командой:

```powershell
flutter run
flutter build apk --release
```

Фото отправляется в Google Gemini для анализа. Персональный API key сохраняется только в локальных настройках приложения на устройстве и не включается в APK. При прямом обращении приложения к Gemini ключ всё равно может быть извлечён с устройства опытным пользователем; для публичного сервиса рекомендуется серверный proxy.

### Источник каталога продуктов

Компактный каталог содержит распространённые продукты и значения КБЖУ на 100 г из набора [USDA FoodData Central — SR Legacy](https://fdc.nal.usda.gov/download-datasets/). В каталоге сохранены идентификаторы записей и исходные английские описания USDA. Справочные значения зависят от конкретного вида и способа приготовления продукта и могут отличаться от данных на упаковке.

## 🛠 Стек технологий

* **Framework:** Flutter (Dart)
* **Database / Local Storage:** Hive & Hive Flutter (быстрое NoSQL хранилище ключ-значение)
* **State Management:** Vanilla StatefulWidget + ValueListenableBuilder (для реактивного обновления UI при изменении настроек)
* **Localization & Formatting:** `intl` (полная поддержка русскоязычного календаря и дат)
